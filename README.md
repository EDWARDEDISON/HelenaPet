# 海伦娜 · 盲女桌宠（皮肤专属波纹版）

一个完全离线的 Windows 桌面宠物「海伦娜」，自带 16 套皮肤、专属盲杖与波纹特效、表情互动、对话、作息与折叠面板等。本版波纹会随皮肤自动配色。

## 系统要求

- Windows 10 / 11（64 位）
- 已安装 **.NET Framework 4.x**（Windows 10/11 通常自带，无需额外安装）

## 如何运行

任选其一：

1. **双击运行** `HelenaPet.exe`（推荐，直接启动桌宠）。
2. 或双击 `启动盲女.cmd`（效果相同，会自动定位到本目录并启动）。

> 桌宠启动后会出现在屏幕边缘，用鼠标左键拖动搬家，右键打开设置面板。

## 首次运行的提示说明

如果你看到 **「Windows 已保护你的电脑」/ SmartScreen 提示**，或杀毒软件询问是否允许运行：

- 这是因为 `HelenaPet.exe` 是**个人编译、未做数字签名**的程序（所有个人程序都如此），并非病毒。
- 本程序**完全离线**，无联网、无麦克风录音、无 AI 对话、不读取任何个人信息。
- 如需继续使用，点击「更多信息 → 仍要运行 / 允许」即可。

## 基本操作

- 左键：短按聊天、长按摸头、拖动搬家
- 右键：短按打开面板
- 右键按住：0.45–0.9 秒跳一下；0.9–1.6 秒跳两下；满 1.6 秒跳三下（每次落地出现随皮肤配色的波纹）
- 双击：切换心情；滚轮：调整大小

更详细的说明见目录内各 `*.md` 文档（`使用说明.md`、`新版使用指南.md`、`皮肤专属波纹说明.md` 等）。

## 目录结构

- `HelenaPet.exe`、`启动盲女.cmd`：程序本体与启动脚本
- `assets/`、`skins/`：图片素材、16 套皮肤与各自绑定素材
- `settings.json` / `interaction.json` / `dialogue.json`：个人偏好、互动参数、台词
- `source/`：C# 源码（可用 `source/build.ps1` 重新编译）
- `preview/`：WPF 实际渲染截图与演示视频
- `Live2D准备/`：素材分层 PSD（用于后续 Live2D 制作）

## 运行所需的最小文件

朋友电脑上只需保留以下内容即可正常使用：

```
HelenaPet.exe
启动盲女.cmd
assets/
skins/
settings.json
interaction.json
dialogue.json
```

其余（`source/`、`preview/`、`Live2D准备/`、QA 记录）为开发/存档资料，不影响运行。
