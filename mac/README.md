# 海伦娜桌宠 · Mac 测试版

适用 **macOS 13 Ventura 或更新版本**。苹果芯片（M1、M2、M3、M4 等）选择 `arm64`；Intel 芯片选择 `x64`。在苹果菜单 → 关于本机可查看芯片型号。

## 使用

1. 下载与你的芯片相符的 `HelenaPet-Mac-arm64.zip` 或 `HelenaPet-Mac-x64.zip`。
2. 完整解压，把 `HelenaPet.app` 拖到“应用程序”文件夹，再双击打开。无需自行安装 Node.js、Python、.NET 或配置 AI。
3. 菜单栏会出现小头像，从这里打开互动面板、找回桌宠和退出。它不会一直占据 Dock。

左键轻点部位对话，长按摸头，按住左键移动拖动。滚轮 / 触控板双指滑动可调整大小。右键轻点打开面板；右键按住约 0.45 / 0.9 / 1.6 秒，松开后跳 1 / 2 / 3 次。触控板可用双指轻点打开右键菜单，蓄力操作更适合实体鼠标。

面板可切换 16 个皮肤选项、16 种表情、6 种小装饰及 11 个挂件；可以读书、翻页、吃甜品、探杖、调节视线和字号，以及关闭闲置睡眠或日常小跳。对话为预置台词，原作台词会标注来源。

## 数据与权限

程序完全使用随包素材和预置台词；不连接 AI，不下载模型。偏好保存在 `~/Library/Application Support/HelenaPet/preferences.json`，不会修改 Windows 版文件。更新 APP 时保留这份偏好；要重置，可退出后备份并移走它。

鼠标跟随仅使用光标位置。没有请求麦克风、摄像头、辅助功能或屏幕录制权限；不安装后台服务，不添加开机启动项。

## 测试版范围

这是复用原素材的独立跨平台渲染实现，细部形变与 Windows / WPF 版可能有差别。Windows 专属制作工具、PSD 导出、自由编辑台词和部位规则等开发功能暂未迁移。

公开发布前会在 GitHub 的苹果芯片与 Intel Mac 环境分别构建、启动并执行皮肤 / 表情 / 道具渲染自检。自动化检查不代替真实用户的长时间、多显示器、Spaces 和触控板体验测试；欢迎提供系统版本、芯片和具体问题。

源码在 `mac/`；维护者可安装 Node.js 24 与 pnpm，在此目录执行 `pnpm install --frozen-lockfile --ignore-scripts`、`pnpm exec install-electron --no`，再运行 `pnpm start`。普通使用者无需这些步骤。
