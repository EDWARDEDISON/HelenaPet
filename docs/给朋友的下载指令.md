# 给朋友的一句话下载指令

直接复制下面这一段给有电脑操作能力的 AI：

> 请帮我在 Windows 10/11 电脑上，从 https://github.com/EDWARDEDISON/HelenaPet/releases/latest/download/HelenaPet-Windows.zip 下载海伦娜桌宠，完整解压到用户可写的新文件夹，保留 assets、skins 和随包文件并运行 HelenaPet.exe；无需安装 Python、Node.js 或配置 AI；如果你不能直接操作电脑，请给我下载链接和手动步骤，遇到系统安全拦截先告知我，不要关闭安全防护。

## 不借助 AI 也可以

1. [点击下载 Windows 运行包](https://github.com/EDWARDEDISON/HelenaPet/releases/latest/download/HelenaPet-Windows.zip)。
2. 右键 `HelenaPet-Windows.zip` → 全部解压缩。
3. 打开 `HelenaPet` 文件夹，双击 `HelenaPet.exe`。

普通聊天版 AI 不一定能操作电脑、下载文件或运行程序；它应提供步骤，不能仅回复“已经安装完成”。国内网络如果暂时打不开 GitHub，请稍后重试或反馈实际错误，不必安装额外运行环境。

## 旧指令需要改的地方

- `archive/refs/heads/master.zip` 是完整源码仓库压缩包，不是专供朋友使用的精简版本；旧路径本身有效，完整解压后也可启动。
- 必须完整解压并保留 `assets/`、`skins/` 等文件，EXE 不能单独运行。
- “更多信息 → 仍要运行”不是每台 Windows 都提供的按钮，也不能保证程序在所有电脑上正常启动。先核对来源并阅读安全提示，不要自动关闭防护。
- 本程序无数字签名。SHA-256 只能核对文件是否一致，不能证明安全。
