# 圆鼓脸与小装饰：制作记录

本轮使用内置 image_gen 制作两张独立鼓脸前脸图层及一张六种装饰的透明图集，再用程序的网格与分层渲染接入。没有把整头截图当作唯一动画素材。

## 已接入的素材

- `skins/original/face-pout-v2.png`：保留有刘海的鼓脸。
- `skins/original-no-bangs/face-pout-v2.png`：保留无刘海的鼓脸。
- `assets/decorations-v1.png`、`decorations.json`：猫耳、鹿角、兔耳、小皇冠、蝴蝶结、星星夹。

原本的脸、帽子、眼镜与后发素材继续保留。鼓脸时切换专用前脸，约 240 ms 过渡；纽扣眼、动态嘴型与转头保持独立。普通表情仍使用原脸，不会永久变胖。

## 使用

右键角色 → 衣橱 → 帽顶小装饰。默认小猫耳朵，可选其他五种或“不戴装饰”。一次佩戴一种装饰，两款发型通用，选择会保存。装饰跟随头部与帽子，耳朵／鹿角位于帽后，皇冠／蝴蝶结／星星夹位于帽前。

右键 → 此刻的心情 → 鼓脸，查看新的圆鼓脸。读书、投喂、探杖时同样可切换。进食优先使用开口和咀嚼嘴型，脸颊仍可保持鼓起。

生成素材与整头预览的组装方式不同，最终以程序渲染为准。`preview/六种装饰预览-original-no-bangs.png`、`六种装饰预览-original.png` 为实际渲染；`鼓脸过渡与跟随.mp4` 和 `六种装饰跟随演示.mp4` 分别展示过渡与佩戴。

源码：`source/HeadMotion.cs`、`App.cs`、`Accessories.cs`；检查结果：`pout-qa-results.txt`、`decoration-qa-results.txt`。
